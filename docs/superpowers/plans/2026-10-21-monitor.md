## Contract

- Purpose: inspect real telemetry, bot/player conversations, delivery, generation latency, tokens, queue and bridge health in one dense screen.
- Primary actions: select session/bot/type, search, pause the visible feed, inspect raw JSON, export captured records.
- Layout: operational header; eight compact instruments; main conversation/event tables; right column of transport, bot roster, tokens and queue; bottom diagnostics. Target viewports 1600x1000 and 390x844.
- Visual direction: graphite instrument panels, amber emphasis, cyan telemetry, mint healthy state and red faults; clear mono numerals, quiet borders, compact row spacing. No decorative imagery required: charts and event tables are the inspectable assets.
- States: loading keeps panel geometry; empty explains missing game telemetry; error shows connection/retry; partial preserves known counters and labels unknown token data; success shows live updates; permission state not applicable because this is a read-only loopback monitor with no external account connection of its own.
- No invented live events or token numbers. Explicit demo mode, if offered, is visibly labelled and never alters actual state.
- Token usage is authoritative App Server data, deduplicated per thread; cached input/reasoning are subsets, not extra totals. Published bot replies are distinct from observed game acknowledgements.
- Runtime and logs are under D:\ChatGPT. HTTP listens only on 127.0.0.1. No public deployment or controls that execute arbitrary commands.
