# AMAI LLM Chat

Локальный экспериментальный модуль для Warcraft III 3.0.1 и AMAI 3.7.0.
Ботами управляет AMAI; разговоры генерирует `gpt-6.1-sol`, effort `low`, через
отдельный Codex App Server с обычной авторизацией пользователя.

## Что реализовано

- Ответы на свободный текст игрока и реакции на смерть/воскрешение героев.
- Три разных характера, русский сленг, короткая история текущего матча.
- Не более одной генерации одновременно; интервалы 8 секунд на всех ботов
  и 20 секунд на одного бота. Устаревшие реакции пропускаются.
- Шаблонные разговорные реплики AMAI отключаются командой `-llm on`.
  При недоступной модели бот молчит. Ответы Commander сохраняются.
- Генератор не получает shell, браузер, файловые инструменты и личные MCP.
- Работа только при одном активном человеческом игроке на локальном компьютере.

## Первый запуск: отдельная тестовая карта

1. Запустить `bridge/Start.ps1` через PowerShell. Он подготавливает почтовый
   каталог на D: и ждёт карту. Для подробного окна диагностики:

   ```powershell
   & 'D:\ChatGPT\Projects\AMAI-LLM-Chat\bridge\Start.ps1'
   ```

2. После завершения текущего матча открыть в одиночной игре свою карту
   `AMAI-LLM/AMAI-LLM-Probe.w3x` (имя в списке: **AMAI LLM Probe**).
   Карта создана отдельно, на основе Amazonia. Она содержит свой сборщик
   и не требует замены глобальных файлов игры.
3. Сборщик включится автоматически через 4 секунды. Мост вернёт диагностическую
   русскую строку с кавычками и обратным слешем. Только после подтверждения
   от игры включится LLM.
4. Через 12 секунд после включения карта создаст тестового героя и убьёт его
   юнитом компьютера. Это намеренно созданный проверочный эпизод.
   Можно написать сообщение в чат и проверить ответ.

Тестовая карта отключает стандартное завершение по победе/поражению и раскрывает
туман войны. Она нужна для проверки транспорта, а не для обычного матча.
Её можно пересобрать командой `node bridge/build-probe.mjs`.

## Установка для обычных матчей

Глобальная установка разрешается скриптом только после полученного от игры
подтверждения кругового обмена. Завершить матч и выйти из Warcraft III, затем:

```powershell
& 'D:\ChatGPT\Projects\AMAI-LLM-Chat\bridge\Install.ps1'
```

Заменяются только `common.ai` и `Blizzard.j` в `_retail_/Scripts`.
Исходные файлы и их хеши сохраняются в `runtime`. Остальные ресурсы Quenching
и кампаний установщик не копирует. Для возврата:

```powershell
& 'D:\ChatGPT\Projects\AMAI-LLM-Chat\bridge\Install.ps1' -Restore
```

В новом локальном melee-матче написать `-llm on`. Отключение: `-llm off`.
До включения модуль не собирает чат/смерти и действует обычный AMAI.

**Ограничение первой версии:** сборщик рассчитан на JASS-карты. Карты Lua
не используют расширенный `Blizzard.j`; для них потребуется отдельная
Lua-интеграция. Глобальная установка сама по себе её не добавляет.
Наличие JASS не ограничивает выбор HD-графики.

## Проверки и диагностика

```powershell
# Проверки протокола, очереди и работы процесса на имитации игровых файлов:
& 'D:\ChatGPT\Tools\node\node.exe' --test 'D:\ChatGPT\Projects\AMAI-LLM-Chat\bridge\test.mjs'
# Проверка модели, авторизации и конфигурации без запуска игры:
& 'D:\ChatGPT\Projects\AMAI-LLM-Chat\bridge\Start.ps1' -Doctor
# Компиляция исходных JASS/AI с обоими парсерами:
& 'D:\ChatGPT\Projects\AMAI-LLM-Chat\bridge\Build.ps1'
```

Журнал: `D:\ChatGPT\Cache\AMAI-LLM\bridge.jsonl`. Он содержит сообщения
игрока и переданные события матча. `transport-verified.json` появляется только
после приёма подтверждения через почтовый файл игры; сам по себе тест Node.js
не подтверждает работу движка Warcraft.

Настройки интервалов, каталогов и модели: `bridge/config.json`.
Характеры: `bridge/personas.json`.
При запуске из другого места можно указать `AMAI_CODEX_EXE`.
Для останова скрытого фонового процесса: `bridge/Stop.ps1`.

Все создаваемые рабочие файлы находятся на D:. В профиле Warcraft создаются
только ссылки на конкретные каталоги модуля.

## Подтверждённые результаты текущей сборки

- Node.js: проверки формата, кириллицы, экранирования, повторов, ошибок RPC,
  очереди, интервалов и смены матча; проверка процесса на имитации файлов.
- AMAI REFORGED: сборка и проверка двумя штатными JASS-парсерами.
- Codex App Server: настоящий ответ `gpt-6.1-sol` с effort `low` на синтетический
  эпизод; это не телеметрия активного пользовательского матча.
- Проверка в Warcraft III пока ожидает запуска отдельной тестовой карты.

Исходный AMAI: SMUnlimited/AMAI, версия 3.7.0. Лицензия и авторство сохранены
в исходном репозитории; этот локальный проект не публикуется.
